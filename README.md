# 毕业祝福 NFC 页面

这是给 NT3H2111 NFC 标签使用的静态网页。手机碰 NFC 后打开这个网页，页面显示毕业祝福、学校背景图和学院 Logo。

## 使用方法

1. 把学校背景图片放到 `assets` 文件夹，命名为 `school-bg.png`。
2. 把学院 Logo 放到 `assets` 文件夹，命名为 `college-logo.png`。
3. 打开 `index.html` 本地预览。
4. 把修改后的文件重新上传到 GitHub 仓库。
5. GitHub Pages 更新后，用原来的 NFC 网址访问即可。

示例 NFC 写入内容：

```text
https://zb1102.github.io/campus-map-nfc/
```

注意：iPhone 通常会先弹出 NFC 提示，点击后才打开页面，这是系统限制。
